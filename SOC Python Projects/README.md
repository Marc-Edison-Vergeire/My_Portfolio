# 🐍 SOC Python Projects

Cybersecurity requires efficiency and speed. This directory contains custom automated Python scripts I developed to automate repetitive SOC tasks, parse logs, and enhance incident response workflows.

**Focus:** Leveraging scripting to reduce Mean Time to Detect (MTTD) and Mean Time to Respond (MTTR).

---

## 🎯 Engineering Philosophy

In a modern Security Operations Center, manual processes can create bottlenecks that delay critical defense actions. My approach to development focuses on creating modular, well-documented scripts designed to integrate seamlessly into an analyst's daily workflow. By automating administrative tasks and log parsing, I aim to free up valuable time for proactive threat hunting and deep-dive investigations.

---

## 🛠️ Core Capabilities Demonstrated

* **Log Parsing & Normalization:** Extracting relevant indicators of compromise (IoCs) and structuring raw log data into readable formats.
* **API Integration:** Connecting with threat intelligence feeds and security platforms to enrich alert context dynamically.
* **Workflow Optimization:** Eliminating manual steps in the triage process to accelerate decision-making during security incidents.
