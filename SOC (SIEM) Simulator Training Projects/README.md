## 💻 Platforms & Training Environments

* **Objective:** Developing tactical proficiency and independent problem-solving skills by operating within a realistic, unguided interface that mirrors true-to-life corporate alert triaging, log analysis, and incident containment procedures.

### 🔹 TryHackMe SOC Simulator Training
* **Focus:** Blue-team investigations involving web application attacks, malware containment, and phishing analysis within a simulated SOC ticket system.
* **Objective:** Cultivating a strong technical foundation through hands-on labs focused on tool mastery, network forensics, and analyzing diverse adversary methodologies.

---

## 🎯 Investigation & Triage Methodology

Across both platforms, my approach to resolving security incidents follows a structured incident response lifecycle:
1. **Alert Verification:** Analyzing initial alert metadata to determine if the event is a true positive or a false positive.
2. **Artifact & Log Analysis:** Deep-diving into network traffic, endpoint event logs, and malicious files to understand the scope of the activity.
3. **Containment & Remediation:** Implementing isolation strategies to stop the spread of threats and documenting necessary steps to patch the vulnerability.
